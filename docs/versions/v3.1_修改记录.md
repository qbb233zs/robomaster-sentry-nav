## 1. 本版结论

**v3.1 相对 v3.0 没有任何源码、配置、地图或仿真资源差异。**

这不是“找不到修改内容”，而是逐文件比较结果确实为零差异：

- v3.0 解压树与 v3.1 解压树的 `diff -ru` 没有输出；

因此，当前 `nav-master-ccut-QY-newcccutNav2-3.1.zip` 应视为 **3.0 的内容副本/重新打包版本**，不能据此写出“3.1 修复了某个 Bug”。如果本意是让 3.1 包含新修复，那么这个压缩包没有把修复内容打进去。

### 2.2 ZIP 条目比较

读取 ZIP 中央目录，不只看压缩包文件哈希，而是比较真正影响解压内容的字段：

```python
import zipfile

paths = [
    "nav-master-ccut-QY-newcccutNav2-3.0.zip",
    "nav-master-ccut-QY-newcccutNav2-3.1.zip",
]

snapshots = []
for path in paths:
    with zipfile.ZipFile(path) as archive:
        entries = [
            (info.filename, info.file_size, info.CRC, info.compress_size)
            for info in archive.infolist()
        ]
    snapshots.append(entries)

print(snapshots[0] == snapshots[1])
```

结果：

```text
True
```

比较字段：

```text
条目名 filename
未压缩大小 file_size
CRC32 CRC
压缩后大小 compress_size
```

这四个字段全部一致，说明当前 ZIP 内的文件内容一致。
